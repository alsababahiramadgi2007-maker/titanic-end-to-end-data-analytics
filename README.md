# Titanic End-to-End Data Analytics Project

## Internship
SWYNEX Technologies – Task 4

## Project Overview
This project presents an end-to-end data analytics case study using the Titanic dataset. It covers data cleaning, exploratory data analysis, data visualization, and dashboard creation.

## Tools and Technologies
- Python
- Pandas
- Google Colab
- Microsoft Excel
- Microsoft Power BI

## Project Workflow

### 1. Data Cleaning
- Handled missing values.
- Removed duplicate records.
- Standardized data types and values.
- Validated the cleaned dataset.

**Final Dataset:**
- Rows: 781
- Columns: 15
- Missing Values: 0
- Duplicate Records: 0

### 2. Exploratory Data Analysis
Performed analysis using Microsoft Excel to identify passenger patterns and survival trends.

### 3. Power BI Dashboard
Created an interactive dashboard with KPI cards, charts, and slicers to explore Titanic passenger survival.

### 4. Key Findings
- Total Passengers: 781
- Survived: 323
- Not Survived: 458
- Female Passengers: 293
- Male Passengers: 488

## Project Structure

- `01_Data_Cleaning` – Python notebook and cleaned dataset
- `02_Excel_Analysis` – Excel EDA file and charts
- `03_PowerBI_Dashboard` – Power BI dashboard
- `04_Final_Report` – Final project report in Word and PDF formats

## Conclusion
This project demonstrates the complete data analytics workflow, from cleaning raw data to analyzing patterns and presenting insights through an interactive dashboard.
